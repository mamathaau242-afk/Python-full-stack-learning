# Arithmetic Operators in Python

Arithmetic operators are used to perform standard mathematical calculations.

- **Addition (`+`)**
  - Example: `5 + 3`
  - Result: `8`

- **Subtraction (`-`)**
  - Example: `5 - 3`
  - Result: `2`

- **Multiplication (`*`)**
  - Example: `5 * 3`
  - Result: `15`

- **Division (`/`)**
  - Always returns a float
  - Example: `5 / 2`
  - Result: `2.5`

- **Floor Division (`//`)**
  - Rounds down to the nearest whole number
  - Example: `5 // 2`
  - Result: `2`

- **Modulus (`%`)**
  - Returns the remainder
  - Example: `5 % 2`
  - Result: `1`

- **Exponentiation (`**`)**
  - Power operation
  - Example: `5 ** 2`
  - Result: `25`

---

### 💻 Example Code
```python
a, b = 5, 3

print(a + b)   # 8
print(a - b)   # 2
print(a * b)   # 15
print(a / 2)   # 2.5
print(a // 2)  # 2
print(a % 2)   # 1
print(a ** 2)  # 25
